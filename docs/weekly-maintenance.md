# 独立周报入口维护

周报继续由独立服务 `weekly-report` 提供，入口为 `https://issane.cn/weekly/`，数据位于 `/var/lib/weekly-report/`。主站 HTTPS 发布模板保留 `weekly-report*.conf` 引用，避免发布后丢失转发。

手动工作流 `维护独立周报入口` 使用现有服务器 Secrets。默认只检查；`repair` 仅在独立服务正常、现有转发片段与仓库一致、HTTPS 插入位置唯一时补回引用。先备份配置，`nginx -t` 后 reload；入口未返回预期的 401 时恢复原配置。

工作流只在日志中显示运行状态和最近周报文件名。最近八份运行时周报及当前周报登录配置使用调用者的一次性证书加密后返回；私钥只留调用者本机，禁止提交私钥、解密后的正文或凭据。GitHub 公开日志中不输出原文和密码。工作流不改周报内容、账号、数据目录或其他站点配置。
