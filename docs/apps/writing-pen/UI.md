# 写作·笔 UI 稿（文字版设计规范）

> 原创视觉设计。主视觉取「纸墨 + 暖色点缀」，与主站 Issane 的干净风格呼应；不做液态玻璃仿制。

## 1. 设计基调

- **主题**：首期两套 —— `夜·墨纸`（深色，默认）与 `日·暖纸`（浅色）；CSS variables 切换。
- **字体**：界面 system-ui / "PingFang SC" / "Microsoft YaHei"；正文编辑区 `"Noto Serif SC", "Source Han Serif SC", serif` 衬线（写作感）。
- **色板（夜）**：底 `#16151a`，面板 `#1f1e24`，描边 `#31303a`，正文 `#e8e6e0`，次级 `#9a97a3`；强调「朱砂」`#e05d44`（主按钮/当前章），辅色「黛青」`#5e81ac`。
- **类型色（图谱/标签通用）**：人物 朱砂 `#e05d44` · 地点 黛青 `#5e81ac` · 势力 金 `#c9a227` · 物件 紫藤 `#8f6fc9` · 线索 松绿 `#5e9c76` · 事件 中性 `#a49fb0`。
- **圆角**：面板 14px、卡片 10px、胶囊 999px。阴影只用于浮层。

## 2. 信息架构与布局

```
┌ 顶栏 52px：〔←书架〕作品名 · 统计(字数/今日) ｜ 视图页签(写作/大纲/图谱/设定/灵感/统计) ｜ 导入 导出 ⚙ ┐
│ 写作：左 280px 章节树 ｜ 中 编辑区(最大 720px 居中) ｜ 右 300px 页签(提要/关联/线索/批注)          │
│ 大纲：左 260px (阶段+剧情线列表) ｜ 中 矩阵横向滚动 ｜ 右 340px 事件详情(选中时浮出)               │
│ 图谱：全幅画布 ｜ 左上 类型过滤 chips ｜ 右 320px 节点/边详情 ｜ 右下 缩放控件                     │
│ 设定：左 240px 分类(人物/地点/势力/物件/线索) ｜ 中 卡片网格 ｜ 点卡开右侧滑出详情                 │
│ 灵感/统计：单列卡片流 / 图表页                                                                  │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

## 3. 关键界面要素

### 3.1 章节树
- 卷头：「第一卷 · 取经缘起」+ 章数；折叠箭头；`+ 新章`。
- 章行：标题 + 字数（右对齐灰字）；当前章左侧 2px 朱砂条 + 底色微亮。
- 底部统计条：今日 n/目标 · 连续 d 天。

### 3.2 编辑区
- 章头：卷 · 章面包屑 + 章题（衬线大字）+ 分隔饰线（细横线 + 菱形点，纯 CSS）。
- 正文：min-height 60vh 的 textarea（衬线 19px / 行高 1.9）；自动保存指示「已保存 · 刚刚」。
- 高亮：只读预览层对人物/地点名加下划色点（编辑态不做 inline 混排，避免 contentEditable 复杂度）。
- Aa 浮钮：字号/行距/页宽 popover。

### 3.3 出场人物卡（右栏 / 关联）
- 横卡：左侧 40px 色块首字（人物色），右侧 名称 + 身份胶囊 + 两行简介（截断）+ 别名灰字。

### 3.4 大纲矩阵（连线 UI 的主场）
- 列头 = 阶段（「01 取经缘起 · 第1–8章」），行头 = 剧情线（色点 + 名 + 事件数）。
- 事件卡：标题 + 章节区间；状态点（已写 绿 / 待撰写 灰 / 待想 虚线卡）。
- **连线**：SVG 路径层，`M a.x,a.y C …` 贝塞尔；标签胶囊（因果=朱砂底、呼应=黛青底）钉在曲线中点；点线 hover 加粗。
- 事件详情右栏：标题、摘要 textarea、剧情线 chips、出场 chips（从设定选）、细纲 checklist（+/勾选）、钩子单行、关联列表（「因果 ← 抵港与告密」「呼应 → 布索尼神父」样式 + 连到另一张卡按钮）。

### 3.5 关系图谱（核心亮点）
- 底：细网格（20px 点阵）。
- 节点：64px 圆角方卡（色块首字 24px + 名 12px），事件节点为窄长条。
- 边：贝塞尔曲线 1.5px，箭头表示方向；中点标签胶囊（关系词，如 对立/师徒/伏笔→揭晓）。
- 交互：锚点拖出连线（虚线预览）、框选暂不做、Delete 删选中、双击空白建节点、双击节点改名。
- 图例 chips：六类显隐过滤。

### 3.6 线索卡
- 状态徽标：埋下（松绿空心）/ 已呼应（黛青）/ 已揭晓（朱砂实心）；「埋设于 第4章 · 回收于 第27章」；痕迹列表（「记录到的痕迹」小节，可增删）。

## 4. 文案与示例数据

- 示例书《山海遗事》（原创短篇设定：云溪镇调查「潮生祭」异象），人物 5、地点 4、势力 2、线索 4、大纲 3 阶段 × 3 剧情线 × 9 事件，用于演示连线与图谱。
- 全部 UI 文案中文；按钮用动词（新建章节 / 连到另一张卡 / 导出全书）。
